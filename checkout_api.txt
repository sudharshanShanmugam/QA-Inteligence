
POST /api/cart/add
- Add item to cart
- Body: { product_id, quantity, user_id }
- States: EMPTY → ACTIVE

POST /api/cart/apply-coupon
- Apply discount coupon to cart
- Body: { cart_id, coupon_code }
- States: ACTIVE → COUPON_APPLIED
- Errors: COUPON_EXPIRED, COUPON_INVALID, COUPON_ALREADY_USED

POST /api/checkout/initiate
- Begin checkout flow
- Body: { cart_id, user_id }
- States: COUPON_APPLIED / ACTIVE → CHECKOUT_PENDING

POST /api/payment/process
- Process payment
- Body: { checkout_id, payment_method, amount }
- States: CHECKOUT_PENDING → PAYMENT_PROCESSING → ORDER_PLACED / PAYMENT_FAILED

POST /api/order/confirm
- Confirm and finalize order
- States: ORDER_PLACED → ORDER_CONFIRMED

POST /api/order/cancel
- Cancel an order
- States: ORDER_CONFIRMED → CANCELLED (only within 30 minutes)

GET /api/inventory/check
- Check stock before checkout
- Returns: { product_id, available_qty, reserved_qty }
